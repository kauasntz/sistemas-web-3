Jogo da velha (Tic-tac-toe) com todas funcionalidades básicas: jogabilidade alternada entre X e O, detecção de vitória, e botão para reiniciar.

1. Interface visual atrativa com design responsivo usando Tailwind CSS
2. Alternância automática entre jogadores X e O
3. Detecção de vitória em todas as combinações possíveis (linhas, colunas e diagonais)
4. Detecção de empate quando todas as casas são preenchidas sem vencedor
5. Status do jogo mostrando qual jogador é o próximo ou quem venceu
6. Botão "Novo Jogo" para reiniciar a partida
7. Prevenção de jogadas inválidas (não permite jogar em casas ocupadas ou após o fim do jogo)
